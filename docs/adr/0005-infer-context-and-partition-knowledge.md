# Infer context and partition coaching knowledge

Anthon will infer the dominant performance context from the conversation, ask only when ambiguity would change the coaching move, and accept explicit correction or switching without a mandatory selector. Identity and communication preferences remain person-wide, while goals, pressures, routines, attempts, and learned evidence belong to a performance context; Anthon may propose promoting a repeated contextual pattern to person-wide knowledge, but the coached person must explicitly confirm the promotion.
