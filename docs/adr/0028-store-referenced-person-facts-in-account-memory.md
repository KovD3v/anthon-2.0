# Store referenced-person facts in account memory

Anthon saves durable facts that the account holder shares about another person in the account holder's existing memory. Every such fact keeps the referenced person's name or unambiguous relationship in its key and value, and it never updates the account holder's profile or preferences. Anthon does not create separate person profiles or memory stores. Ordinary, sensitive, and temporary facts follow the same confirmation and durability rules as other memory. This supersedes ADR-0002 and the referenced-person exclusion in ADR-0019.
