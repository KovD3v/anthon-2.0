# Measure coaching value without reading content into analytics

Anthon will record `value_created` when the coached person expresses or accepts useful understanding or a controllable action, and `evidence_received` when they later report what happened. The model's unsupported self-assessment cannot establish either event. Response feedback remains an unobtrusive supporting signal with an optional reason after negative feedback. Operational security and reliability telemetry is separate from optional product analytics; optional analytics begins disabled until explicit consent and can be withdrawn in Web settings. Product analytics uses a pseudonymous identifier and excludes names, email addresses, dates of birth, profile facts, memory values, documents, and conversation text.
