# Gate real-user experiments and AI changes

Every real-user experiment variant will preserve the same coaching scope, safety, privacy, and standards. Silent experiments are limited to low-risk presentation or demonstrably equivalent execution changes; side-by-side model or coaching comparisons require clear notice and explicit participation. Prompt, model, memory, and routing changes require representative offline evaluation, privacy and boundary regressions, latency and cost checks, a staged cohort, monitored success criteria, and an immediate rollback path before broad release.
