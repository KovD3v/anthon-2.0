# Provide a full account export

Anthon will provide an account-wide portable export containing profile information, preferences, performance contexts, memories, conversations from every channel, uploaded-document metadata, and applicable billing and usage records. The package will combine human-readable files with structured JSON. It will exclude internal traces, security controls, hidden model reasoning, and information belonging to other people. This replaces the current single-Web-chat export as the complete portability boundary without removing convenient per-chat export.
