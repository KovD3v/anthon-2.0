# Create performance contexts only for durable knowledge

Anthon will not create a performance context for every conversation. It will create one when the first durable context-specific item is about to be saved, infer a short name, and let the account holder rename, merge, archive, or correct it later. The user does not administer contexts before chatting, and changing contexts never creates a second personal identity. This keeps context partitioning real without turning ordinary coaching into taxonomy work.
