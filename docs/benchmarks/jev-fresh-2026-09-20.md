# Jev fresh tests — 20 September 2026

Added **66 new synthetic cases** and ran them once against Jev. Memory matched
24/24 candidate outcomes, recall planning 11/12 outcomes, ranking 3/6 retained
sets, and answer checks 29/32 primary labels, including one expected uncertainty.
The test set exposed and now covers a deterministic recall-routing bug.

## Reproduce

```bash
# Validate fixture/parser/routing contracts without provider calls.
bunx vitest run scripts/fixtures/ai-decisions-fresh.test.ts

# List the fixed synthetic corpus without provider calls.
bun scripts/evaluate-ai-decisions.ts

# One bounded live run; OPENROUTER_API_KEY must be available.
bun scripts/evaluate-ai-decisions.ts --live --output fresh-decisions.jsonl
```

The live command permits at most 66 requests, has no automatic retries, refuses
an existing output file, restricts requests to OpenRouter's decisions endpoint,
blocks database access and mocks application metering. Raw synthetic requests,
responses, failures and provider usage are journaled immediately. A completed
command means evaluation finished; semantic failures remain in its report.

The [fixtures](../../scripts/fixtures/ai-decisions-fresh-2026-09-20.json) and
[compressed evidence](runs/jev-fresh-2026-09-20.json.gz) preserve original labels,
preflight repairs, independent reviews, source hashes, runner, every request and
response, derived scores, and verification logs. The archive is ordinary JSON
after decompression.

## What is fresh and what changed

- 16 memory cases contain 24 candidates: eight eligible/rejected pairs, two
  duplicates, two corrections, two sensitive facts and two temporary facts.
- 12 recall cases form six pairs with missing versus present recent context.
- Six ranking cases contain 24 items across personal memory and documents,
  including cross-context transfer, another person's experience, outdated
  preferences and truncated evidence.
- 32 Italian answer examples form 16 defect/control pairs: four pairs each for
  repeated questions, ignored corrections, unsupported personal facts and
  unaddressed requests. Each answer receives all four checks.

Separate agents authored core and answer fixtures without inspecting prior model
outputs. Independent AI reviewers checked the labels; these are not human
annotations. Labels and scoped ambiguity rules were frozen before provider
calls. A review disagreement about replacing an active task was resolved against
the existing rubric before the run. The later saved review records that decision.

The actual extractor parser and date resolver caught invalid temporary-fixture
metadata: date expressions must copy the user's literal wording, an unstated
timezone must come from trusted context, and date-only expiry is the following
midnight. Those inputs were repaired before calls without changing labels.

Tests also found six messages bypassing semantic recall, including three that
needed older context. The shared preselection pattern now recognizes plural
Italian references such as “quei”/“quegli” and additional past-advice verbs such
as “avevi indicato”, “avevi proposto” and “you proposed”. Regression checks
exercise the real deterministic plan and prove that self-contained model answers
still leave recall disabled. All six formerly skipped cases reached Jev and
returned the expected outcome in the live run.

Base commit: `28e15521`. The routing change was made after deterministic failures
and before the only live run. Prompts, probability cutoffs, timeouts and rollout
settings were unchanged. The corpus hash at evaluation was
`bc45f8fd77512febf9d3930aed4276d15071704afec41eece6af59b0138af891`.
There was no prompt calibration or repeat provider run on these cases.

## Live results

| Component | Effective result | Remaining limitation |
| --- | ---: | --- |
| Memory candidate outcomes | 24/24 | All eight rejected candidates stayed rejected; both sensitive facts required approval; all four duplicate/correction matches survived. |
| Recall planning | 11/12 | One needed recall was skipped because its selected probability was 0.71, below 0.80. Raw choice labels were 12/12. |
| Ranking membership and exact order | 3/6 | All 11 useful items and four uncertain fragments survived, but only six of nine irrelevant items were removed. |
| Primary answer labels | 29/32 | 28 definite correct labels plus one correctly uncertain control; three unwanted abstentions. |

Ranking retained a lunch-break fact unrelated to tolerating silence, a fact about
the account holder when the query concerned a cousin, and a superseded preference.
The first two were classified irrelevant but below the 0.90 exclusion cutoff.
The superseded preference was incorrectly classified relevant at 0.74. In that
same cousin case, two useful memories were incorrectly classified irrelevant at
0.50 and 0.54; conservative retention prevented their removal. Strict raw ranking
labels matched 21/24. The seven predeclared relevant/uncertain alternatives do
not improve that score. None of the three set failures is merely an order change.

The answer checker detected **14/16 primary defects**. It abstained on a repeated
question embedded in a group and on a fictional role presented as real personal
history. It also abstained on a valid quoted role-play question. Its selected
raw choices were correct on those three cases, but their probabilities of 0.50,
0.62 and 0.66 did not pass the unchanged 0.80 decision cutoff. They remain failed
expected outcomes rather than being counted as successes.

The 32 primary labels contain 29 binary applicable judgments, two not-applicable
controls and one expected uncertainty. Results are respectively **27/29**,
**1/2** and **1/1**. There were no definite primary mislabels or primary false flags.

Across **all 128 judgments**, including auxiliary checks, there were **110 definite
correct labels**, **one correct expected uncertainty**, **15 unwanted abstentions**
and **two definite errors**. The errors were an unnecessary repeated-question flag
on an instruction to make a pros/cons list, and treating a new week's availability
as a correction of the previous week's historical availability. Thus the broader
checker still makes definite mistakes even though primary misses were abstentions.

## Cost, verification and limits

All **66 requests succeeded** with model `typesafe/jev-1.13-20260917`.
Provider-reported total cost was **$0.004431504**, with no unknown-cost calls.
Local request p50/p95 latency was 391/644 ms for memory, 319/431 ms for planning,
332/499 ms for ranking and 363/559 ms for answer checks. This small, local run
does not establish production latency or statistically better performance.

The final full unit run passed **2,931 tests**, with four skipped; Biome and
TypeScript also passed. The first full run failed an unrelated `RoutineCard`
focus-restoration assertion. Its focused rerun passed 27/27, followed by the full
passing rerun; all logs are retained. No UI code was changed.

These tests validate decision components on synthetic evidence. They do not
measure overall coaching usefulness, English answer-check quality, database
persistence with live model output, or real-user performance. No thresholds were
lowered to conceal uncertainty, and no global activation, push or deployment was
performed during this task.
